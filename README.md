
# 236248_TranCongPhiHai

## 1. Giới thiệu
Dự án quản lý món ăn, cho phép xem, tìm kiếm, thêm,
cập nhật và xóa món ăn.

## 2. Công nghệ sử dụng
- Frontend: React, Vite
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Quản lý mã nguồn: GitHub
- Đóng gói: Docker
- Triển khai: Render

## 3. Cấu trúc dự án
- backend/: mã nguồn API
- frontend/: mã nguồn giao diện
- README.md: tài liệu dự án
- .gitignore: các file không đưa lên GitHub

## 4. Cài đặt
Hướng dẫn cài đặt và chạy ứng dụng sẽ được cập nhật
sau khi hoàn thành backend và frontend.
